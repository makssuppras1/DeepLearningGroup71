# Format

You are required to submit a written report. The report should be no more than 4 pages, excluding the reference list and AI declaration, and must use the provided template. The reference and the AI declaration do not count toward the page limit. You must include the AI declaration on the last page of the report.

The report must also include a link to your project's GitHub repository. Among the files in the repository should be a Jupyter notebook that ideally should recreate the main results of your report. If some of your data is confidential, then use some shareable data instead.

# Evaluation

Your project will be evaluated based on how well you demonstrate the course's learning objectives relevant to the project, which can be summarised as follows:

- Demonstrate knowledge of deep learning terminology relevant to the project.
- Understand and explain the model choices and limitations for the project.
- Apply and analyse results from deep learning models in the project.
- Plan, delimit and carry out an applied or methods-oriented project in collaboration with fellow students and the project supervisor.
- Assess and summarise the project results in relation to aims, methods and available data.
- Carry out the project and interpret results using a computational framework for GPU programming, such as PyTorch.
- Structure and present project results in a final technical report including the problem formulation, descriptions of methods, experiments, evaluation and conclusion.
